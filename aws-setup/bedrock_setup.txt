================================================================
  BEDROCK SETUP — AI MODEL ACCESS (AMAZON NOVA LITE)
================================================================

IMPORTANT:
  As of Oct 2025, AWS retired the manual "Model access" dashboard.
  Most serverless models (including Amazon Nova) are now ENABLED
  BY DEFAULT — no access request needed!

MODEL USED:
  - Model ID: amazon.nova-lite-v1:0
  - Provider: Amazon (1st party)
  - Supports: Multimodal (text + image + video)
  - API: Converse API (recommended)
  - Available by default: ✅ YES

VERIFY IT WORKS:

1. Go to AWS Console → Amazon Bedrock
2. In the left sidebar → "Chat" under "Playgrounds"
3. Select model: Amazon Nova Lite
4. Upload a test aircraft image
5. Type: "What aircraft is in this image?"
6. Verify you get a response

   If the model works in the playground, it will work in Lambda.

REGION AVAILABILITY:
  Amazon Nova Lite is available in:
    - us-east-1 (N. Virginia)
    - us-west-2 (Oregon)
    - And other major regions

  Ensure your Lambda function is in a region where Nova is available.
  The Lambda code uses us-east-1 by default.
  If using a different region, update region in lambda_function.py.

ALTERNATIVE MODELS (also default-available):
  - Amazon Nova Pro: amazon.nova-pro-v1:0
    (More capable, higher cost, also multimodal)
  - Amazon Nova Micro: amazon.nova-micro-v1:0
    (Text-only, does NOT support images)

  To switch to Nova Pro: update BEDROCK_MODEL_ID in lambda_function.py

IAM PERMISSIONS:
  Your Lambda execution role needs:
    - bedrock:InvokeModel (for invoke_model API)
    - bedrock:Converse (for converse API — this is what we use)

  The managed policy "AmazonBedrockFullAccess" covers both.

TROUBLESHOOTING:
  - "Access denied": Check IAM permissions on Lambda role
  - "Model not found": Verify region supports Amazon Nova
  - "Validation error": Ensure image is valid base64 JPEG/PNG
  - Lambda timeout: Increase Lambda timeout to 60+ seconds
